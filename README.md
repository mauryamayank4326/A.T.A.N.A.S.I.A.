# M.A.U.R.Y.A.

**Multi-source Analysis for Uncovering Reconnaissance & Yielding Actionable-intel**

Modern OSINT & Threat Recon Dashboard.

## Mission

M.A.U.R.Y.A. is an asynchronous External Attack Surface Management
(EASM) and Cyber Threat Intelligence (CTI) reconnaissance platform.

Longer-term goals include:

- asynchronous network collection;
- modular OSINT workers;
- relational intelligence persistence;
- fault-isolated reconnaissance tasks;
- operational attack-surface visualization;
- structured forensic export.

## Current Status

Development milestone: 0.25.0

Lifecycle: Day 25 / 50

Day 25 connects the two reconnaissance sources without coupling their internal implementations.

The integration layer will:
1. Accept a ShodanSearchResult.
2. Accept a collection of TCPPortObservation objects.
3. Validate that the Shodan result belongs to the requested domain.
4. Preserve both source result collections.
5. Calculate useful reconnaissance metrics.
6. Expose a consistent result object for future API and orchestration integration.
Design decision: Shodan observations and live TCP observations will remain separately identifiable. We will not assume that a Shodan IP and a TCP hostname represent the same endpoint without verified resolution.

The app reads settings with the `MAURYA_` prefix. By default, it uses
`sqlite+aiosqlite:///./data/osint.db` and serves the health endpoint at
`http://127.0.0.1:8000/api/v1/health`. The API prefix defaults to `/api/v1`;
it can be overridden through application settings.

Run the app:

```bash
uvicorn app.main:app --reload
```

pytest -v
